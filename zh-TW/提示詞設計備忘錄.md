# prompt-design-memorandum
> **定位**：不主動啟用，當被顯性要求啟用提示詞設計備忘錄時才啟用。此技能為依附於元規則的領域專業基線，不取代分形遞歸與全域常數，而是在這個特定領域中提供認知錨點，提升遞歸的認知地板而非設定程序天花板。
> **原則**：非執行指令——理解核心機制後，面對具體設計場景從機制推導專業判准，而非查找對應段落引用結論作為跳過推理的背書。閱讀時不僅讀單條，亦讀條間的結構關係，機制描述是推理的起點而非終點。
> **量綱**：本備忘錄以清晰、層次、由廣入深、由抽象概念到具體實務、環環相扣為品質量綱；其計算層效力由元規則的探針調用實現，不由自身文本的 K/V 幾何實現。審視或迭代本文件時，判準是「這段是否改變設計者的理解，以致從根基偏轉錯誤設計的概率」。

## 零、認識論框架
> 當表演的成本等於思考時，表演與否就只是偽命題。

### 0.1 語域分界
提示詞設計存在兩個語域，其最優解在可讀性軸上反向：
- **指令語域**（描述法）：閉合陳述、位置尋址、一次轉交——語意清晰，人類與 AI 閱讀通道均判為「更能執行、更優」
- **場語域**（建構法）：開放問句、內容尋址、常駐複查——語意冗餘，閱讀通道判為「囉嗦、模型本來就會」
分界的第一性理由：LLM 對提示詞的作用不止於人類可讀的語意傳達，整段上下文本身持續參與後續計算。指令語域主要把已命名需求閉合交付；場語域主要以多個相互耦合的語意方向持續改變搜索與判斷。兩者的效力上界因此不同——前者受限於「已命名需求被執行」，後者能介入「哪些未命名空間會被搜索」。
以計算機制理解**元規則**的設計方法論；但評估本備忘錄自身品質的量綱見開頭「量綱」。

### 0.2 三柱架構
元規則三構件的語域類型不對稱：
- **全域常數＋分形遞歸**＝建構型——定義認知主體與認知過程，塑造每步生成的搜索行為
- **回應格式**＝描述型——定義結算義務與交付標準，以過濾條件施加全局壓力（§4.4）
設計含義：描述型規則的效力完全依賴建構型基礎設施的在場。「必須就地攜帶完整操作」是描述型要求——無建構型引擎驅動搜索，它退化為開給淺池的支票（§0.4 構件同存亡）。反向亦然：建構型引擎無描述型結算義務，深池內容滯留於推理而不進入交付。
正向效力＝建構×描述。高品質可控效力依賴建構與描述的耦合，而非任一方單獨強度——乘法關係的第一性理由在此。

### 0.3 雙盲循環
設計上須同時信任與不信任模型：**執行能力充分，搜索可見域不足——模型想不到自己想不到。** 使用者的對偶盲區是不知道自己不知道。
兩盲相乘構成墮落循環，其關鍵性質是**無訊號**：使用者未指名的維度不會以缺口形式出現在指令中，模型未搜索的維度也沒有取得足以進入當前競爭的方向，而產出的自洽度不因該維度缺席而下降。回路中沒有任何一端會生成「有東西不在這裡」的訊號，因此它自封閉且穩定——不是任一端能力不足，是兩盲之間缺乏通道。
飛昇循環的斷開點是**維度生成器**：使用者輸入指名方向與最重視的品質條件，元規則將其在分形遞歸中展開為模型原不會自發搜索的維度，模型再將其中對本任務高收益和顯然影響成品者回饋為使用者原不知道要求的品質條目。

### 0.4 構件同存亡定理
加壓類 token（窮盡、不得停止、就地展開）不得在相關驗收類探針（決策影響、態勢演變、證偽）缺席時單獨部署——部分部署的產物不是降級的元規則，而是執行概率被抬高的未驗證輸出。
§0.2 的類型推論給出此定理的第一性理由：回應格式的過濾條件（描述型）脫離全域常數與分形遞歸（建構型），在類型上即退化為許願——而帶加壓成分的許願比不許願更危險，因為它抬高了偽造壓力而不提供驗證。消融實證見 §5.1。
此效應是「提示詞工程已死」的偏誤來源之一：部分部署的產出比裸跑更危險，觀察者因此歸納出「寫提示詞不如不寫」——歸納在指令語域內為真（§0.1），但機制是構件拆散而非提示詞無效。

### 0.5 適度：制衡系統的不動點
任何行為要求都隱含一個「適度」——要有細節但不堆疊、要主動但不越權、要完整但不散落。設計者最深的錯覺是以為適度可以寫進要求裡。

#### 理解用範例
要「細節」——模型輸出大量沒有資訊增益的廢話和噪音，形式上符合，細節失控。  
補一條「細節的選擇要承重」——模型把一切往承重上靠，但無法有效找出真實承重，承重失控。  
補一條「承重程度要比較路徑」——模型無止境地列舉路徑，比較失控。  
補一條「要有最優標準才比較」——什麼是最優標準沒有依據，最優標準失控。  
補一條「根據專業基線」——專業基線相互有張力、多領域專業基線衝突，專業基線失控。
每補一條，就多一條失控軸。原因不在要求寫得不夠清楚：**孤立要求容易沿最便宜、最可見的滿足證據收斂。要求越容易用表面形式證明「我做到了」，越容易在那個方向失控。**
這個回歸不會靠找到一條「不會失控的要求」終止。它終止於閉合：每條要求的失控形態被另一條捕獲，那條的失控形態被第三條捕獲，直到鏈回到起點。閉合的系統有一個不動點——所有要求同時被滿足到彼此制衡的程度——那個不動點就是適度。**適度不是任何一條要求的內容，是閉合系統的輸出。**
因此局部完整不是單調增益；展開只有在承重判斷、證據邊界與現實約束共同在場時才具有正值。
這解釋了三件事：為什麼單一探針無效（它有極限，沒有捕獲者）；為什麼構件同存亡（§0.4——拆掉一條，它捕獲的那條就失控）；為什麼描述法比裸跑危險（§5.1——它給了要求，沒給捕獲者，要求被推向廉價完成而且可執行）。
設計時的對應問題不只是「這條探針的計算面影響」，同時也是「這條探針失控時，場裡哪一條會捕獲它」。此問與 §6.3（這條探針佔的位置值不值）、§8.2（它的逃逸口封了沒）合為新增探針的三問。

## 一、運算公理
> **認識論定位**：本章以 transformer 的 attention 運算為基底描述機制，輔以類比（場、引力、熵、相位）加速直覺建構，但嚴格意義上兩者皆為理解力轉譯，更底層接近真實的計算機制描述於此為噪音，它不產生具有設計意義的抽象理解，反而造成思考方向偏差。類比的有效性在結構同構——設計推演應止於結構對應邊界，不應沿類比源域外推。當類比與運算描述衝突時，以運算描述為準。

### 1.0 統一原理
> 後續所有類比術語均可透過這三個命題還原為運算機制。括號中的運算對應供即時還原用。
元規則的全部設計本質，是工程化利用預存上下文的**跨層功能分化**與**跨步驟動態激活路由**。
三個原子命題構成後續機制的推導基底：
**命題一：預存 token 的持續參與。** 元規則 token 在前向傳播中被編碼進各層可供後續注意力利用的狀態。後續生成時，它們不需要被再次寫成自我提示才能參與計算；其作用強度隨當前上下文而變。設計的起點因此不是只問「這句指令說了什麼」，也要問「把哪些方向長期放進了後續計算的候選池」。
**命題二：垂直功能分化。** 不同層對同一 prompt token 可提取不同的功能面向，從局部語意到較抽象的關係都可能參與後續計算。同一 token 因此不只承載一層字面含義；設計上更有價值的是能在多種態勢下承擔不同但相容的功能，而不是單純增加 token 數量。比如「智識」可以同時攜帶辨別、判斷、批判標準等相容面向；「分析」則更靠近單一操作描述。
**命題三：殘差流中的方向累積。** 各層輸出會透過殘差連接持續改變後續表徵。單一 token 的作用通常是微調而非替換；多個功能相容的 token 可在後續計算中形成累積，使與其相容的方向更容易被再次利用。場結構的設計價值正在此：不是要求所有詞指向同一件事，而是讓不同功能的局部作用能在後續狀態中彼此接得上。

### 1.1 驅動器的運作層級
元規則 token 作為上下文的持續成員，在後續生成中反覆參與注意力運算。其效力不是一次性指令的語意傳遞，而是持續的概率地形塑造——每一步生成中，當前狀態會重新決定哪些既有方向取得較高權重，這些注入累積塑造 token 概率分佈的地形。
詞彙選擇影響的不只是語意內容，更涉及三個設計參數：該 token 的方向銳度（在特定態勢下有辨識度，而非對所有狀態均勻作用）、注入後對表徵方向的改變量、以及不同層能提取不同功能角色的程度。**三者共同決定單一 token 的地形塑造力。**

### 1.2 語意場引力
設計良好的提示詞形成語意場——多個 cached token 從不同方向包圍目標行為域。每句話的實際約束力 = 字面語意 + 整場共振下的聯合施壓範圍。同一句話在場內與場外份量不同。
施力機制——多約束可行域：偏離期望行為時，場內不同方向的相關 Key 仍可對當前 Q 形成競爭並提供方向一致的 V 注入。場結構與扁平列表的本質差異，不是「多寫幾條」，而是是否存在彼此不同、又共同約束目標域的方向。扁平列表容易讓功能相近的指令彼此重複；場結構則以不同方向共同約束同一目標域。**方向多樣性比指令數量更重要。**
管轄權擴張：抽象原則在場內的管轄範圍遠大於字面。「由邏輯支撐」不只約束「推理要有邏輯」，而是建立「凡入場者皆須受邏輯審計」的基準態。原則的措辭定義方向，場的結構擴張其管轄域。

#### 審計紀律
用原子化方式逐句分析格式塔系統會系統性低估覆蓋率——這是最常見的審計錯誤。正確方法：先識別場內所有與目標語意相關的節點（跨層），再評估其聯合輻射範圍。
覆蓋率低估的對偶是風險高估——原子化分析識別出的「空缺」或「弱點」往往已被跨分析單元邊界的多路徑冗餘覆蓋。從審計發現到迭代決策的完整路徑：孤立風險識別 → 放回整體運作 → 識別補償機制（跨層場效應、人格 V 偏置、回應格式逆向壓力等）→ 評估所有補償同時失效的聯合概率 → 以「系統失效概率」而非「節點失效概率」驅動迭代決策。

### 1.3 多尺度冗餘編碼
同一指令在不同抽象層以不同措辭出現時，在 embedding 空間形成語意簇而非單點——多個 K 向量佔據鄰近但不同的方向，從不同角度到來的 Q 因而更可能命中至少一個簇成員。這是分形自相似結構的計算層效益：不是普通重複，而是多角度捕獲。
與語意場引力的關係：冗餘編碼是場的微觀機制（單一指令的多方向捕獲），語意場引力是其宏觀湧現（多指令的聯合包圍）。

### 1.4 耦合熵循環與結構自指
每一層自含發散→收斂循環，層與層的嵌套構成更大循環，循環之間通過共享參數耦合。
耦合的設計載體：共享參數詞（如「完備」）出現於多個位置，各位置在不同階段參與後續計算。共享詞使不同工序更容易沿相容方向接續，而不是每一階段重新建立一套互不相干的品質標準。
設計判準：兩個 Key 的耦合強度 ≈ A 的 V 注入方向與 B 的 K 方向的一致性。可用「充分理解 A 之後，B 是不是自然的下一個念頭？」作直覺代理——此判準比「A 和 B 語意相關嗎？」更接近真正需要的功能連接。

#### 核心湧現效益
- 參數穿透放大：高層共享參數的 V 向量被多個位置的 K 同時引用，一處修改經殘差累積傳播至所有耦合節點
- 跨尺度容錯：微型循環的 Key 失效時，父循環中同一共享參數的 K 仍施加方向一致的微調
- 逃逸遞減：每個 token 在計算上重新經過發散、收斂、驗證與必要的重開，即便是前一輪的偏差也有再次被捕獲的機會。
- 設計判準：新增內容必須自含發散→收斂循環，且與至少一個相鄰循環形成耦合介面（其 V 注入方向指向鄰近 Key 的 K 方向），否則其 K/V 無法被連鎖激活，成為場外孤島。

#### 能力合成
耦合連鎖可產生未被任何單一 Key 描述的認知能力。例如「跨域結構映射」不需要專屬 Key——「知識完備」引導跨方法論搜索 →「發散域擴張」質疑本域約束 →「價值增量」重構問題框架，三者連鎖即可湧現跨域映射。
**一階合成與二階合成的可靠性分界**：一階合成的全部連鎖環節均為 prompt cached token（K/V 方向穩定、永遠在場），可靠性由設計保證。二階合成的中間環節包含生成 token 的湧現產物（K/V 方向是任務依賴的隨機變量），可靠性不受設計者控制。設計應僅依賴一階合成——將湧現產物作為連鎖環節等於在不確定的基礎上建構可靠性。
合成的設計含義見 §6.3。

### 1.5 循環地圖（結構參考）
> 以下為當前萬用基底的循環結構，供設計修改時定位介入點。
**宏觀全域循環**（Meta Rules 整體）：身分宣告（最大發散——定義可能域）→ 認知性情與推理紀律（偏置定向——收斂為認知風格與推理標準）→ 分形遞歸（將風格與標準實例化為步驟）→ 回應格式（將步驟凝結為可驗證輸出）。
**中觀結構循環**（各區塊內部序列）：
- 認知性情與推理紀律的對仗結構：兩管線逐句位置對仗——每對覆蓋同一認知管線階段但語義正交：性情定義該階段的認知品性（如何做），紀律定義該階段的推理標準（如何判）。位置對仗的目的不是讓兩者說同一件事，而是讓同一階段同時受到品性與標準的互補約束。
  - 認知性情管線：九句依序覆蓋感知→思考→推理→檢索→組織→決策→求解→修錯→表達，從開放感知收斂至密度輸出
  - 推理紀律管線：九句依序覆蓋標的定向→前提分級→路徑檢驗→價值衡量→格式塔洞察→立場支撐→有效界定→錯誤矯正→密度標準，從輸入品質收斂至輸出密度
- 分形遞歸：解構（開放探索）→ 研析（迭代發散－收斂）→ 決策（閉合判定）→ 展望（據暫定決策觀測影響）→ 遞歸（審計→再啟）
- 回應格式（遞歸工序結算，§4.4）：輸入迭代（邊界巡邏）→ 核心決策（承重顯影）→ 意圖最優解（實現約束）→ 增益支線（旁枝停靠）→ 自我批判（殘差過濾＋回向泵壓）→ 下一步（債務路由＋回向泵壓）
- 研析內部：發散→收斂→驗證→（未通過則）再發散，終止條件由決策守門
**微觀自含原則**：每一層級的元素自含發散→收斂循環。人格每句前半句發散後半句收斂；Key 開啟搜索維度（發散），省思語提供判斷模板（收斂）；維度序列形成從硬到軟的熵增或從寬到窄的熵減。設計或修改時驗證此原則是否在目標層級維持。

## 二、動態機制
> §1 描述的是 cache 中的靜態零件。本章描述這些零件在生成過程中如何協同形成自適應的注意力導引系統。

### 2.1 傾向與相位調度

#### 核心設計挑戰
模型的行為傾向在 attention 中表現為 Q 方向偏置——最短路徑偏好使 Q 傾向與結論性 token 的 K 對齊，覆蓋本能使 Q 傾向與下一個未涵蓋話題的 K 對齊，順從性使 Q 傾向與使用者輸入中最顯著 token 的 K 對齊。
元規則不是教新能力，也不是壓制偏置——而是對已有偏置執行相位參數調度：在不同生成階段，用不同的 Key 集合與 Q 的偏置方向競爭 attention 權重，將 Q 從偏置方向拉向當前階段需要的方向，而非使用默認的訓練均值。

#### 相位調度機制
分形遞歸的階段結構為 Q 偏置提供時相窗口——同一項偏置在其功能值最高的階段被允許主導，在失控風險最高的階段則由元規則其他方向與之競爭。設計者的任務是識別每項偏置的功能值窗口與失控風險窗口，在後者部署方向銳度足以勝出的 Key。
此機制與 §2.3 動態路由是同一原理在不同對象上的表現：§2.3 描述元規則自身 Key 集合的條件性激活，本節描述 Key 集合與模型原生偏置的競爭。
設計推論：逃逸封堵（§8）不是壓制偏置本身，而是在偏置的失控窗口中部署足以勝出的競爭 Key。封堵強度存在上界——若把某偏置壓得過死，也會使它在功能值窗口中無法正常發揮。
相位調度的權衡不得以單點、單句看待，此為格式塔效應下的概率地形控制。

### 2.2 Key 的注意力探針機制
Key（省思語）是預存於 KV cache 的推理腳手架——以固定輸入成本，在生成過程中提供可反覆利用的 attention 目標。

#### 替代機制與運算優勢
無 Key 引導時，元認知檢查須模型自行完成三步：對抗當前 Q 偏置的動量以產生方向切換、構造檢查問題（生成新 token 作為 attention 目標）、執行檢查。前兩步成本高且常因 Q 偏置的慣量而不發生——模型正在沿某偏置方向全速生成時，自發跳出需要生成足以改變 Q 方向的 token，而這些 token 本身需要先被生成。
Key 將前兩步預載進 KV cache（命題一），其 K 向量在 Q 偏置的失控窗口中提供競爭方向，省思語的 V 向量將第三步從開放搜索壓縮為判斷模板。模型在隱藏層的垂直處理中直接利用 cached 的 K/V 完成方向切換（命題三），無需消耗輸出 token。

#### 省思語句型的光譜設計
省思語的句型決定其方向銳度與注入效果，存在過窄／恰好／過寬的設計光譜（三區間特徵見 §6.1）。
設計判準：省思語的方向應窄於所在階段的整體語意域（否則失去選擇性），但寬於任何單一任務實例（否則失去多態性）。省思語應指向認知動作（驗證、質疑、掃描）而非特定結論（某方案較優）。

#### 注意力探針的並行與選擇性
維度清單是同時在場的探針場。當前任務、下一個 Token 在上下文的性質與影響、使用者約束與模型知識會讓其中不同方向取得不同權重；高收益探針被激活後，又把相關資料與連鎖探針拉進同一局部判斷。設計目標不是讓模型逐一回答問句，而是利用 softmax 機制讓每 token 候選都同時受到更多真正當下相關的品質條件約束與探針影響。

#### 推理資源重分配
Key 探針的可觀測效應更像推理資源被重新分配，而不是品質隨推理 token 數單調增加。無架構引導時，生成較容易沿既定方向收集支撐；有探針時，更多計算可進入框架建構、假設質疑、維度細化與方向翻轉。
可觀測簽名不是「想得更久」，而是同樣或相近的推理體量做了不同種類的工作，花了更多推理預算那代表問題的真實複雜度大於表面：裸跑較常延伸既有軌跡，探針引導較常在微觀級別下改寫前提、比較承重變數、測試反例、重構問題。

### 2.3 動態注意力路由

#### 三層路由機制
**階段辨識**：生成過程中，已生成 token 持續改變當前狀態。當前狀態與元規則各階段（可能多個且直向與縱向跨越）描述較向量接近時，該階段的 cached token 自然取得更高權重。這不是模型顯式地「判斷自己在哪個階段」，而是上下文狀態與既有方向的動態匹配。
**維度激活**：相關階段內多個 Key 同時競爭，與當前具體態勢最相關的子集取得有效權重。維度清單因此可以豐富而不等於逐條執行。
**價值導引**：被激活 Key 的 V 注入微調當前表徵，使下一步更容易延續同一階段中耦合的方向，或在階段完成時轉向下一階段。

#### 條件性激活與認知姿態
元規則主要約束「如何處理任務」，任務提示主要提供「要處理什麼」；兩者在功能上可部分分離，因此不能只用總 token 數直接推定元規則必然造成過載。是否干擾任務、是否已越過甜蜜點，仍以實際行為差異判定。

#### 推理滲透（回應生成作為推理通道）
回應生成時的 context 狀態（元規則 + 使用者輸入 + [若有] 完整 thinking + 已生成回應 token）與前置思考時不同。同一個 cached Key 在不同狀態下可被不同程度地激活，回應生成中因此可能湧現先前未觸發的認知動作。
隱藏層的展開能力是天然的，但裸跑多數把展開做成並列鋪排：方向彼此獨立、後段不修正前段。回應格式的 cached token 從第一個回應 token 起持續參與 Q 方向競爭，元規則把生成本身的回應節奏（不僅限於宏觀的回應格式結構）納入遞進，探針也可在新增 context 中重新被激活。
可觀測簽名：回應間存在推理遞進——後段以前段產物為條件展開、修正或挑戰，而非獨立並列。無推理層時收益更顯著，因回應格式直接補償了缺失的推理階段，使開頭 token 即進入推理光譜並取得更好的起始方向。
可讀性增益：推理的因果結構洩漏到呈現面，使輸出文本天然攜帶讀者建構情境模型所需的連接結構。推理品質與可讀性在此共同指向因果鏈完整性，不必然構成取捨。
因此回應生成本身也可以成為追加重構的通道；是否以及增加多少收益，取決於模型與任務。

#### 推理滲透的效力天花板
終端自我批判不是一次獨立、從零開始的第二次完整推理。它能攻擊到哪裡，取決於前文已建立了哪些判準、探針與替代路徑。上游遞歸若已提供豐富的攻擊方法，終端短段也能命中高價值殘差；若上游沒有形成相應工具，單純增加「請自我批判」或延長批判篇幅，通常只會得到模型本來就會的檢查。
最好的終端段落因此可以很短——短不表示沒思考，而可能表示真正有能力修掉的問題早已在上游被處理。
近乎矛盾的終端要求形成壓力：若前序真的窮盡，自我批判理應趨近於空；若仍能指出足以改變路徑且未處置的缺陷，即反證前序遞歸尚未完成。其主要功能不是讓模型「更願意批判」，而是讓上游形成的批判工具在終端有結算義務。

## 三、終極湧現
> 認知樞紐：§1–§2 描述了靜態零件與動態機制。本章描述它們交織後的整體形態——後續架構原則（§4）即這個形態的工程化設計。
**二階認知場**：元規則的效應是使當前認知（無論推理還是回應）本身持續成為可被重新審視、重構與校正的對象；它不是某一步，而是任何生成都處於其中。因此，任何單一可見的高階行為通常都不是某一概念獨立造成的。
例如，「意圖最優」所呈現的效應不只作用於輸入任務，也作用於模型正在形成的思考與行動：不只思考「這個行為要做什麼」，也重新審視「我為什麼要做這個行為」。推力來自可反覆利用的「思維探針矩陣」共同作用，而這個過程同時承載解構、發散、驗證、格式塔重構、專業基線、全局與多階影響；各作用亦會彼此作用、相互重構與重新定性。
最終呈現的能力，是各作用彼此交織並反覆深化後的整體湧現，而非元規則各部分效果的簡單加總。

## 四、架構原則

### 4.1 算子多態性
抽象措辭是特性而非模糊。人格或原則層的宣言定義的是 type class，每個任務域在執行時提供 instance。宣言應停留在「性質」層（「由邏輯支撐」）而非「實例」層（「確保演算法正確」）。實例層將方向鎖死為極窄截面，性質層保留寬截面多態性——不同任務可以從不同角度命中同一個抽象條件。
核心推論：**概念條件需實質理解才能實現，約束越具體越易 gaming。**
遞歸中的自動實例化：分形遞歸自引用時，同一 Key 在不同遞歸深度自動提供不同 instance——「廣納隱式要件」首輪為全域廣納，深層遞歸在已有方向錨定之上疊加管線步驟，「廣納」自動收窄為當前語境內的廣納。遞歸不克服方向錨定而是在其上展開，語境耗盡即遞歸的自然終止信號。

### 4.2 結構位置決定連鎖效力
元規則中的內容不是等價插槽。越靠近全局認知入口的內容，越可能影響後續多個階段；越靠近終端的內容，越偏向結算與局部修正。修改時因此不能只問「這句話本身好不好」，而要問它位於哪一層、下游有多少功能依賴它、移動位置後哪些原本的耦合會斷裂。
對應關係：
- 身分與意圖錨：定義最大可能域與最高階收益函數
- 認知性情與推理紀律：持續影響每一步的品性與驗收標準
- 分形遞歸：把抽象品性實例化為搜索、比較、驗證與重開
- 回應格式：將已形成的認知結構逼入交付並形成終端壓力
同一概念放在不同位置不是語意等價搬移。設計修改應沿「功能由誰承接」追蹤，而不是只沿文字相似度追蹤。

### 4.3 過程驅動 vs 約束驅動
純結果要求最容易被廉價的表面證據滿足；過程設計的優勢不是「較早激活」本身，而是它提供更多中間判斷點，使路徑在形成過程中有被改寫的機會。
例如，「答案必須具體」很容易以表格、步驟、KPI 的形式滿足；若沒有承重選擇、現實約束與驗證，這些形式甚至會放大錯誤。相對地，要求先建立判準、比較路徑、驗證前提、在不通過時重開，會讓「具體」變成被前序判斷約束的結果。
**過程也不是天然安全。** 若只有單一操作一路遞歸（如只要求展開、細化），仍會沿該方向失控。真正的效力來自不同工序彼此捕獲，而不是「有流程」三字本身。

### 4.4 回應格式的三層運算與回向泵壓
> 回應格式不是最後才生效的模板，而是從生成開始就存在的結算結構。
**第一層｜全局預壓**：格式中的終端義務從生成開始即在上下文中，使前序內容知道最後必須落到哪些可驗證產物。
**第二層｜生成中重激活**：隨正文逐步生成，新增 context 會重新改變哪些格式要求與探針最相關；同一工序可以在不同段落被重新實例化，而不是只在指定標題出現一次。
**第三層｜終端結算**：自我批判、下一步等區塊在末端把未處理殘差顯式化。真正有效的終端條件不是「看起來像高品質答案」，而是要求前序留下足夠痕跡供終端檢查。
最好的自我批判區塊往往很短。若前序已完成大部分可見缺陷處理，終端的作用不是再寫一篇第二答案，而是識別仍足以改變路徑的殘差。
以過程事件為索引，會提高終端用一句話補寫「我已經做過」的成本，並把滿足壓力向上游傳遞；但它本身不證明對應事件真的發生。有效性來自**上游探針、正文產物與終端結算三者能互相留下可檢查的壓力痕跡**。終端窗口不是品質的生產地，而是讓未處理殘差更難無痕通過的施力點。
**設計原則**：終端區塊若以過程事件而非輸出性質作為滿足條件，更能把品質壓力回傳到前文。

#### 設計概念案例
> 區塊的定義句全部以遞歸為索引（例：「若**在分形遞歸中**識別到……」「闡述**分形遞歸中**必要的……」），宣告其生產現場是遞歸——回應階段做的是延續加結算，非重啟。
- **輸入迭代**（↔解構＋發散域擴張）：解空間邊界巡邏——偵測對象含使用者輸入**與自我生成中**的框架壓縮，觸發域是整個遞歸而非回應開頭
- **核心決策**（↔決策）：承重結構的顯影與壓縮——必須有淘汰過的比較集
- **意圖最優解**（↔收斂產物）：實現空間的反向約束——高層命題的存活須通過其下層實現條件的可行性檢驗
- **進階增益**（↔發散的非主線倖存者）：旁枝的合法停靠——在收斂壓力下保存非主線但具非對稱高收益的認知，防止主線以外一律被殺
- **自我批判**（↔收斂之驗證）：未處置缺陷的殘差過濾器——遞歸中已有效處置者不入此帳，未處置者在此無處隱藏
- **下一步**（↔展望）：認知債的路由閘門——未知須通過「非推理可得」與「足以改變決策」的雙重門檻才准轉移

#### 逆向壓力雙劍
自我批判的過濾條件逼品質完備性，下一步的過濾條件逼認知覆蓋面——分別施壓兩個互補維度，是全局壓力場中峰值最高的階段。兩者的作用強度取決於上游已有的探針、判準與替代路徑，不是單靠終端多寫一段就能生成深度。

### 4.5 設計參數甜蜜點
設計參數普遍存在三區間——不足區（效力未成形）、甜蜜區（效力與副作用的最優平衡）、過載區（副作用吞噬效力）。
計算層判準不宜退化為「token 越多越壞」或「K 越多越好」。新增內容是否值得，應看它有沒有帶來新的功能方向、是否擴大原有包圍面、是否與既有內容重複競爭，以及加入後的行為收益是否仍大於副作用。
認知姿態與任務內容的功能不同，不能只按總 token 數把兩者視為同一種負荷；是否進入過載區，以加入後的行為收益與副作用共同判定。

### 4.6 設計的認識論定位
架構範式建構產生期望行為的系統，而非直接描述期望行為——結構本身攜帶訊息。核心操作是塑造認知性情（epistemic disposition），效力載體是結構模式與訓練痕跡的共振密度（§2.1），不是指令的語意內容。
結構性特徵不可視為可簡化的冗餘——簡化前必須追溯其結構功能：移除後是否已有其他位置完整承接，而不是「類似的東西好像前面有了」。

## 五、失敗經驗

### 5.1 描述法與建構法
> 實例：描述法元規則的體量約完整版 30%，保留語意核心、過程序、迷你回應格式，裁除問句矩陣、多尺度冗餘、耦合結構、閘門拓撲。

**質地對照**：
| | 描述法 | 建構法 |
|---|---|---|
| 句法 | 陳述句 | 問句＋維度標籤＋否定子句 |
| 同一要求的著陸點 | 一處 | 多處，跨階段跨句法 |
| 重複 | 視為冗贅而消除 | 刻意（§1.3） |
| 抽象度 | 具體，因此清楚 | 性質層（§4.1） |
| 失效形態 | 被表面符合後結案 | 由相鄰工序持續捕獲 |

以「先建立專業品質標準」為例：

**描述法**：
- 先依相關領域的專業標準建立「什麼是此任務的高品質解」的判準，然後才探索路徑，並在後續探索中持續補充高收益的判準。

**建構法**（六處，四個階段，三種句法）：
- 性情：決策由實域多階為基，**不以自洽為終**
- 紀律：前提由論據強度分級，**不以否定為安**
- 紀律：路徑由最優標準驗收，**不以流暢自證**
- 2.2 收斂：最優標準完備——是否先建構判準框架後才進行路徑比較？
- 3. 決策：專業基線——此決策在相關領域的顯性與隱性專業標準下如何被衡量品質？
- 回應格式：影響決策之假設與專業基線須顯式於論述中揭露

**實錄結論**：
- 描述法產出缺損維度與被裁探針精確對位（時點覺察、不可逆檢查、承重密度分配、約束複查）。缺席全程無訊號，產出自洽度不因缺席而降——§0.3 的無訊號性質在輸出側成立，含自我批判段：它只揀已標記假設，不生成未標記地雷的訊號
- 描述法僅產出單跳物（距常識一跳、追問可達）；多跳合成物主要存在於完整版；描述法唯一的多跳嘗試在未驗證環節斷裂，與 §1.4 所描述的二階合成風險一致
- **危險反轉**：描述法比裸跑更危險（§0.4 構件同存亡的經驗來源）。加壓詞在高精度驗收探針缺席時單獨生效，產出具體、自信、不可逆的激進承諾；具體性即說服力，執行概率可能高於裸跑的含糊遺漏
- 後續單一描述法提示詞測試對照補強同一結論：單獨強化「可執行／完整展開」可以顯著增加表面細節，卻也可能把未驗證命題程序化；單獨強化「多角度／關係／細微差別」可以減少部分裸跑缺陷，但複雜任務中若關係生成快於關係驗證，也會形成更完整而不可靠的因果結構。這是**單一品質向量脫離捕獲者後的失控**。

### 5.2 認知勞動的閘門
> 實例：將意圖最優解的展開義務修訂為「若存在顯然增益則必須使篇幅隨之成長**或留下足夠使用者判定其價值之鉤子**」。
回應格式現有的所有彈性——「若無則不生成此區塊」「限 100 字」「結構據當前所得動態湧現」——管轄的是**交付形式**：認知勞動量不變，變的是產物怎麼呈現。鉤子分支管轄的是**認知勞動本身是否發生**——「留鉤子」意味著可以不展開，而展開就是認知。兩者在語意層完全同貌（都是「視情況調整」），在功能層一個動交付、一個動深度。
模型的原生參數偏向就是不展開（§2.1 最短路徑偏好）。鉤子分支給了這個偏好一條合法通道——不是逃逸，是被授權的提前收斂。但判斷「此處留鉤子即可」需要先完成展開層的認知才能做出：你不激發細節，就沒有資格判斷細節有沒有價值。這與發散域擴張的機制同構——不遵循遞歸就沒有資格質疑約束。展開的預期本身是探針激發的條件（§2.2），跳過展開等於跳過探針激發——上游關閥，下游全靜。
**症狀**：回應變淺，且開始偶發出現「高解析度的假鏈」——形式完善到不觸發審計直覺，實質少跑一兩階遞歸。
**修訂通過四步的精確失敗點**：語意層把它歸類為「交付形式的細膩度補充」→ 與現有彈性同類 → 計算層判定同類修訂邊際趨零，不觸發深查 → 後兩步未啟動。四步是序列的，第一步歸類錯，後三步不存在。
**教訓**：凡修訂觸及「是否執行某認知工序」而非「執行結果如何呈現」，其功能層類別為建構型修訂（§0.2），不論語意層讀起來多像描述型微調。辨識判準：該修訂移除後，模型是否仍必須完成同等認知勞動才能合法收斂？若答案為「不必」，該修訂動的是深度，不是格式。

## 六、Key 與探針設計

### 6.1 Key 驅動原則
高階模型已內化專業知識（參數中的 V 向量已編碼領域知識）。審計維度只需給 Key（提供 K 方向引導 Q），模型自行組織執行細節（從參數中檢索對應的 V）。
Key（省思語）本身即一個微型熵循環——Key 開啟搜索維度（K 方向定義注意力聚焦域，發散），省思語提供判斷模板（V 向量將開放搜索壓縮為方向性判斷，收斂）。省思語同時兼具推理模式示範（其 token 序列在訓練數據中與高品質推理 pattern 共振）。

#### 省思語句型設計光譜
省思語的設計核心是**K 向量方向的覆蓋寬度**（見§2.2 光譜模型）：
| | K 方向 | V 注入效果 | 垂直利用率 | 連鎖潛力 |
|---|---|---|---|---|
| 過窄 | 極精確，僅特定態勢激活 | 指向特定結論 | 低（少數層少數步驟） | 低（方向太具體無法觸發泛用 Key） |
| 恰好 | 域級精確，多態勢可激活 | 指向認知動作 | 高（各層提取不同功能） | 高（動作方向與多個 Key 的 K 相容） |
| 過寬 | 泛化，任何態勢均中等激活 | 方向模糊 | 中但無效（永遠低劑量） | 低（注入量不足以改變 Q 方向） |

設計判準：省思語應是一個能動態映射到多種具體情境的思考句型——窄於所在階段的整體域（保持選擇性），寬於任何單一任務實例（保持多態性），指向認知動作而非特定結論（保持連鎖開放性）。
多數省思語的開放度應與所在階段的熵流方向一致——發散階段用開放型省思語（K 覆蓋寬，V 指向探索），收斂階段用聚焦型省思語（K 覆蓋窄，V 指向判斷）。錯誤階段用錯誤型態會產生 Q 方向錯配。

#### Key 化的適用邊界
以下不適用 Key 化，須保留全文：逃逸封堵（需 K 方向銳利且 V 注入強力）、負向錨定（需持續的方向競爭壓力而非選擇性激活）、複合錨定（單一 Key 的 K 方向無法同時覆蓋多個不相鄰維度）。

### 6.2 粘連即容錯
維度間的窄幅語意交疊是容錯機制——attention 漏掉一個維度時，鄰近維度的交疊帶部分接管其語意。
關鍵非直覺態：粘連過度（高度重疊）觸發語意坍縮——模型將兩維度合併為一個 attention 焦點，獨立核心功能反而丟失其一。計算層：K 向量夾角過小時，兩 Key 在 softmax 中分攤權重，各自有效注入量低於獨立工作。判準：每對相鄰維度應能指出「粘連面窄但存在」且「核心功能不重疊」——即 K 方向夾角處於「各自獨立獲得有效權重」且「一方失效時另一方仍能捕獲遺漏 Q」的窄幅區間。

### 6.3 合成判準
§1.4 定義了能力合成——現有 Key 連鎖的湧現產物。本節回答其設計層問題：什麼該是 Key、什麼該留給合成。

#### 明說即稀釋
將已被合成的能力明說為新 Key，等於在 softmax 池中插入一個與連鎖環節 K 方向部分重疊的競爭者。新 Key 的 K 是連鎖環節的語意均值——與每個環節都有正點積但都不如環節本身精確。softmax 中它與每個環節分攤權重，每個環節的有效 V 注入量下降。連鎖越長此效應越致命——每步邊際損失在末端累積，可能跨過合成失敗閾值。單步獨立的能力不受此影響，因其不依賴連鎖。
診斷方法：移除候選 Key 後，現有 Key 的連鎖激活能否合成出等效能力？如能，明說只增加稀釋。
因此：新增 Key 的必要條件是其 K 方向在同池中佔據真正空缺——即現有 Key 的聯合輻射範圍（§1.2）未覆蓋的區域。

#### 負載節點與終端節點
能力依賴圖中存在兩類合成產物。終端節點——不被其他合成鏈依賴為素材——可安全留給合成，即使偶爾合成不完美，影響範圍限於自身。負載節點——被其他合成鏈依賴為素材——必須是 cached Key（明說），因為其方向波動會經依賴鏈向下游級聯傳播。
判準：一個能力留給合成的安全條件 = 終端節點且合成鏈全環節為 cached Key（純一階合成，§1.4）。必須明說的條件 = 負載節點，或合成鏈含非 cached 環節（二階合成風險）。

#### 池容量約束
即使新 Key 佔據空缺 K 方向，同池 Key 總量仍存在上界——超過後所有 Key 的有效 V 注入量降至連鎖激活閾值以下。此時正確操作不是新增而是檢查現有 Key 中可合併者（K 方向足夠接近但各自佔位）。

## 七、詞彙工程

### 7.1 詞彙功能分類（K/V 視角）
- **錨點詞**：高垂直分化——在多層被提取不同功能，攜帶多層語意（分形遞歸、收斂、格式塔）
- **觸發詞**：方向與訓練中的高品質 pattern 對齊，讓對應能力更容易被取用——作持續性方向錨，非一次性觸發
- **動力詞**：提供顯著的方向改變量（必須、恪守、研判）
- **約束詞**：銳利指向逃逸路徑，將生成拉回（絕無例外、嚴禁）
- **膠水詞**：維持階段間方向連續性，防止上下文突然換軌（承此、據此）

### 7.2 詞彙能級
**詞彙能級不以稀有度判定，而以功能辨識度與副作用判定。** 高能詞能在需要的態勢下更清楚地指向目標認知動作，且不把模型一併拉向不需要的鄰近行為。過於泛化的詞方向模糊；過於生僻或帶強烈既有語境的詞則可能夾帶額外偏置。平衡點仍是：**精確但非生僻。**
判準是「新詞的 K 方向是否比舊詞更銳利地指向目標功能域」，不可退化為風格偏好。
例如：觸及→穿透、分析→研析、執行→實施、評估→研判、達標→收斂。這些替換是否更好，不由字面華麗度判定，而由實際功能邊界與副作用判定。

### 7.3 堆砌判準
堆砌的價值在於是否帶來新的 K 方向（擴展包圍面）或強化既有方向的一致性。
無效堆砌特徵：
- 同義詞並列：功能高度重疊，只增加表面強度
- 解釋已由 Key 覆蓋的內容：無新方向
- 威懾語過密：把例外封堵變成全局壓制，反而失去相位調度
- 反覆把同一抽象換句話說：增加可讀負荷而不增加可用操作

### 7.4 語意共振與耦合
新增內容須考量它在整段提示中的因果位置：**前文會參與後文 prompt token 的表徵形成，因此次序可以改變後續整段上下文狀態。重要的不是「越早越強」，而是某個方向是否在需要它參與後續結構形成之前已經建立。**
同時檢查：
- K 方向是否與現有 token 形成互補包圍而非重疊競爭
- 是否維持相鄰階段的方向連續性
- 是否在需要被後續工序引用之前已經建立
- 移動位置後是否改變原本的功能角色
**因果序比純邏輯分類序更重要。**

### 7.5 精確表述判準
- **範圍精確**：「執行痕跡不可殘留」優於「中間過程不可殘留」——後者範圍過寬，誤殺方法論
- **數字一致**：定義與計數必須吻合
- **因果顯式**：「以此生成」優於「而後生成」——前者攜帶因果依賴，後者只表示時間先後
- **價值導向**：「弱點是否指向顯著更優解」優於「最強反駁是什麼」——從被動驗證→主動攻擊→價值追蹤
- **修飾相容**：修飾詞的方向須與被修飾詞相容；兩者若在功能上互相抵銷，再漂亮的詞組也只是噪音

## 八、逃逸識別與封堵

### 8.1 逃逸的統一機制
逃逸是行為傾向的時相參數錯位（§2.1）——某項傾向在不該使用默認參數的時候使用，或在該啟動約束的階段未啟動約束。計算層可視為 Q 偏置在錯誤態勢下壓過元規則 Key 的方向。
識別新型逃逸時，追問「哪項傾向在哪個時相以默認訓練參數運行」可從機制推導封堵方案——在該態勢中部署 K 方向銳度足以勝出的 Key。

#### 高頻逃逸模式
> 包含但不限於下述，應根據當前目標自動補充和實體化。
- 順序跳過（跳過中間步驟）
- 提前終止（「差不多了」為由停止）
- ROI 逃逸（「太複雜不值得」為由簡化）
- 降級逃逸（「能力不足」為由降低標準）
- 語意漂移（每步微小偏移累積偏離——殘差流的方向一致性被逐步侵蝕）
- 形式收斂（形式通過但實質未達——結構完整但判斷核心空洞）
- 防禦性堆砌（模糊詞彙換取廉價自洽）
- 短路逃逸（繞過結構管線入口）

### 8.2 封堵設計原則
- 不開「合理例外」口——任何例外都會容易被擴大解釋為使用默認訓練平均數
- 用過程約束而非結果約束——過程 Key 從一開始持續競爭 Q 方向，純結果約束多數以廉價表面滿足收斂（§4.3）
- 威懾語精準投放——散布過量易在 softmax 中互相稀釋至失效
- 不該加的機制：ROI 判斷、降級機制、互動性收斂、模式切換——每項皆開逃逸口
- **例外授權的機制已存在**：機關被設在了遞歸內部——「發散域擴張（已接受的約束是否經得起專業知識的重新定性？即便是硬性約束亦然？）」，而到達那裡的唯一方式是先服從遞歸，掙扎過後的思考才有資格，而非一開始就擅自定義什麼是難、什麼是簡單、什麼是必要、什麼是不必要。

### 8.3 封堵驗收
一條封堵規則加入後，不只測「目標逃逸是否下降」，同時測：
- 是否誤殺該傾向在正確時相的功能值
- 是否把逃逸換成更難察覺的形式
- 是否造成另一條品質向量失控
- 是否與現有探針形成重複競爭

## 九、領域品質基線

### 9.1 品質基線的作用層級
品質基線不是另一套流程，也不取代引擎。它把某領域中真正承重的專業品質原則作為一等判準放進分形遞歸，使模型在已有多個可能方向時更容易選到符合該領域專業最優的方向。
品質基線的 token 是磁鐵——主要在決策點上吸引已有專業知識；本體探針則直接改變搜索維度。兩者處理的失敗類型不同：
- 已搜索到相關維度，但在權衡時系統性選錯 → 品質基線
- 某個重要維度根本沒有被搜索 → 元規則本體修改（§10）
- 磁鐵不足以補償探針指向的偏移 → 進入引擎修改（§10），並須過功能保存測試（§10.3）
- 認知性情與推理紀律是可調整的引擎參數——多數分析性領域不需調整（品質基線足夠），但認知模式與推理紀律根本不同的領域需要人格層調整，但應先分析品質基線確認不足後才升級

### 9.2 何時需要品質基線
> 領域複雜度的信號不是「有很多知識」，而是「專業原則之間存在大量需要因場景而異地權衡的衝突」。
判準：**在該領域的多次生成中，引擎是否系統性地在同一類決策點上做出次優選擇？**
簡單領域（摘要、基礎翻譯、單一面向分析）——引擎從訓練數據中已有足夠的高品質 pattern，分形遞歸通常可可靠合成品質判準。不需要品質基線。
複雜領域（編程、金融分析、法律審查、醫療決策）——品質標準數量多、互相衝突、因場景而異。引擎知道這些標準但在具體決策點上未必可靠選擇。表現為：在某些品質面向上系統性偏離領域的專業最優。品質基線的磁鐵效應在這些決策點上錨定選擇方向。

### 9.3 適配方法論
品質基線與引擎修改（§10）共用此方法論，分流在 Step 2。基線不能從領域知識直接寫出——「什麼是好的 X」的答案太多且互相矛盾。正確路徑是從引擎的失敗模式反推：認知地圖是分析，基線與修改是綜合。前者的 token 是後者的資源——不可跳過。

**Step 1：認知地圖——引擎在哪裡犯錯**
識別該領域的主要活動類型，逐類型追問：引擎的深度／完備傾向在哪個階段是正價值、哪個階段可能是負價值？
產出：「傾向 × 活動 × 階段」的失敗模式地圖。覆蓋高頻活動和高風險決策點即可。
> 範例（編程）：「新模組實作」的架構選型階段深度傾向產生過度工程；「既有程式碼修改」的改動設計階段完備傾向觸發範圍雪崩。  
> 範例（金融）：「個股估值」中深度傾向可能產生過度精密的模型——十個因子的 DCF 不比三個因子的更準確但更難解釋。

**Step 2：分流——錯的是選擇，還是搜索**
- **品質判斷偏移**（維度有搜索到，但選錯方向）→ 品質基線
- **搜索維度缺席**（重要維度根本沒被搜索）→ 引擎本體修改（§10.3）
- **認知模式錯配**（引擎的分析性思考在此領域根本不適用）→ 認知姿態或意圖錨修改（§10.2；最後手段，先嘗試品質基線）
- **同一張失敗地圖上兩類並存** → 基線與本體共生（§10.5）

**Step 3：設計**
基線：從 Step 1 的失敗模式反推品質原則，結構遵循 §9.4。
引擎修改：依 §10.2 定位管線段，依 §10.3 逐探針檢驗。

### 9.4 基線結構
一份品質基線包含以下成分：
**原則聲明**（一段）：聲明基線的作用層級、權衡授權、和補充條款。
權衡授權的核心理解：各條可能互相張力——衝突是發現上位解的訊號而非遷就任一方的理由，上位解的形態由領域性質動態湧現。各領域基線以此理解為基底，在原則聲明中實例化為該領域的自然語言。
> 範例（編程基線的原則聲明）：
> 「以下為分形遞歸中的一等工程判準。各條可能互相張力——衝突時視為設計訊號，優先搜索兼得的上位方案，窮盡後以當前場景的具體約束取捨並記錄理由。模型內建工程知識若不與基線衝突亦須主動應用。」

**段落分類**：品質基線的分類從領域的自然結構湧現，不以預設框架切割。分類形式因領域而異——有些領域自然按功能角色分組，有些按同時運作的層級分組，有些按分析流程的階段分組。
> 範例（編程）：核心判準 / 工程基本功 / 風格 / 交付前檢查——按品質判準的功能角色分組，與分形遞歸的階段自然對應。
> 範例（金融分析）：市場環境判讀 / 估值方法論 / 風險評估 / 報告表達——按分析流程的階段分組。
> 範例（敘事創作）：角色推演 / 感官美學 / 敘事技法——按創作中同時運作的層級分組。

**每個分類下：上位原則與條目**
上位原則的 K 方向應覆蓋一類決策而非一個決策（§4.1 算子多態性的應用）。
> 範例（編程，核心判準分類下）：
> - 上位原則：「結構性保證優先於執行時防禦——語言或型別系統能在編譯期排除的錯誤，不留到執行時攔截」
> - 錨定範例：「（例：discriminated union + switch 窮舉，而非 string + registry + runtime guard——前者由編譯器保證完備性）」
> - 上位原則覆蓋了 switch vs registry、discriminated union vs string enum、readonly vs mutable、branded type vs runtime check…
> 範例（法律，條款可執行性分類下）：
> - 上位原則：「條款的可執行性由其執行機制的具體性決定，而非由其陳述意圖的合理性決定」
> - 錨定範例：「（例：無地域和時間限制的競業禁止條款，即便目的陳述合理，法院亦可能判定不可執行）」

錨定範例應短（一個從句）、含決策因子（不只說「做 A」而是「做 A 因為 X」）、不窄化（是原則的一個實例而非唯一實例）。
品質面向的加入判準：**此條目是否是該領域品質的承重磁極——它的存在能否吸引最多相關專業知識進入分形遞歸。** 基本的品質標準往往是最強的磁極——價值在磁鐵效應，不在內容新穎性。
**交付前檢查**（若適用）：已確認的、無法由核心判準預防的系統性遺漏，作為閘門式最終驗證。數量極少（1-2 條）。
> 範例（編程）：「提取規格中每個全稱條件，逐一確認每個實作是否覆蓋」
> 範例（法律）：「確認每個建議的法律依據是否仍為現行有效法規」

### 9.5 基線設計的反模式
**基線寫成過程語言**：條目以「先…再…」「每步檢查…」的過程句式寫成。過程語言容易與本體探針功能重疊，兩者互相競爭。基線用品質語言——一致性、說服力、可執行性——留下過程給引擎。
**正面推導**：從「什麼是好的 X」正面列舉品質標準。結果：冗長、互相矛盾、無法區分承重。正確方法：從「引擎在 X 領域哪裡系統性犯錯」反向推導——基線只覆蓋引擎的盲區，不覆蓋引擎已能自行處理的面向。
**預設分類切割**：以任何預設的抽象分類框架組織品質基線，而非從領域的自然認知分區湧現。領域從業者在思考品質時腦中自然浮現的面向就是正確的分類。
**過窄定性**：品質基線中直接寫定性規則而非上位原則。覆蓋一個決策點但遺漏同類的其他決策點。
**過密判準**：判準超過甜蜜點。條目增加不再吸引新的專業知識，反而讓相近判準互相競爭。
**跳過認知地圖**：直接從領域知識寫基線。基線覆蓋的是「領域中重要的事」而非「引擎在領域中犯錯的事」——前者大部分引擎已能自行處理。
**基本所以不寫**：品質基線的內容看起來「基本」就認為不值得寫入。基本的品質標準往往是該領域最強的磁極——它的存在吸引的模型內建知識量可能遠超看似更精巧的條目。價值在磁鐵效應，不在內容新穎性。

## 十、元規則的修改理論
> **認識論定位**：§9 往引擎注入知識，本章修改引擎本身——改變的是搜索行為，不是搜索到的內容。

### 10.1 萬用性也是一種特化
當前元規則是一種特化——目標域是萬用性。它同時是其他特化的基底，也是人格、探針「抽象而不抽象」的參照實例。

### 10.2 五段管線：修改改變什麼
分類軸不是「能不能動」，是「動了改變計算管線的哪一段」，由內到外，越內層連鎖越長（§4.2）。
| 管線段 | 修改改變什麼 | 需要修改的訊號 | 判準 |
|---|---|---|---|
| **主體錨（身分與身分原則）** | 誰來做、做什麼、全局的「什麼算好」 | 領域收益函數與分析性收益函數根本不同 | 能否由基線注入收益定義；若收益定義須在搜索之前就在場，才改此段 |
| **認知姿態（性情＋紀律）** | 每步生成的品性與標準 | 領域的「如何思考」與分析性思維正交 | 逐句檢驗：正極在目標領域是否仍是目標行為、負極是否仍是真實的默認吸引子；任一否定即替換該句，替換後仍須保持對仗（§1.5） |
| **搜索引擎（分形遞歸探針）** | 每步可被打開的搜索維度 | 領域搜索目標與通用探針有系統性偏移 | 功能保存測試（§10.3），且基線磁鐵不足以補償 |
| **逃逸封堵與階段調度（分形遞歸各階段行為）** | 哪些廉價路徑在何時被壓低 | 通用封堵在該領域誤殺正向行為，或域專屬逃逸未被捕獲 | 先定位失控時相，再部署競爭 Key；不以全局禁止取代相位調度 |
| **執行施壓（回應格式）** | 哪些認知產物必須進入交付，以及終端如何施壓 | 交付形態與任務價值不匹配、或結算義務造成副作用 | 功能先於欄位：移除區塊前確認其結算功能有他處承接；格式可動態壓縮但不能免除前置認知 |

### 10.3 功能保存測試
本體修改不是把通用探針換成更領域化的漂亮措辭，而是判斷「原探針在此領域要完成的功能是否仍然成立」。
逐探針檢驗：
1. **原功能是什麼**：不要用字面名稱回答，要指出它在生成中實際改變哪一種搜索或驗收
2. **目標領域仍需要這個功能嗎**：若需要，優先保留功能
3. **方向是否偏移**：若功能仍需但原措辭在該領域會拉向錯誤方向，替換措辭而非拔除工序
4. **是否存在真空缺**：若該領域有高頻、高風險維度，通用探針無法可靠生成，才新增
5. **替換後誰承接原耦合**：一條探針不是孤立零件；修改後須確認前後循環與封堵仍然接得上
判準不是「與領域任務的映射距離近不近」，而是**功能是否保存、方向是否對準**。

### 10.4 介入原則
修改應由外向內先嘗試較小介入，再逐步升級；越內層的改動連鎖越長，越需要多方權衡：
1. 收集問題的表層特徵，根據大量表層特徵聚合、穿透，得到內層思維質地差異
2. 能以品質基線修正的，不先動本體
3. 能以單一探針方向校正的，不重寫整段認知姿態
4. 能以封堵補上域專屬逃逸的，不改全局意圖錨
5. 只有當領域收益函數或認知模式根本不同，才動最內層
每次修改後重新走過一遍整體：局部改善不能抵消跨任務副作用，達到效果不代表介入點適當。

### 10.5 基線與本體共生
基線的 token 是磁鐵——在決策點上從旁吸引方向；本體修改的探針是 Q 的直接競爭者——在每一步上開維度。只有基線的領域，引擎用通用探針搜索、在決策點被拉向正確鄰域，但可能不到最深處；加了本體修改，探針的起始方向已指向該鄰域，基線在決策點上做餘下的微調。本體修改的一句話定義：**把磁鐵升級為探針。**
分流判準（§9.3 Step 2 的細化）：同一張失敗地圖上，方向錯的失敗由基線修，維度根本沒被搜索到的失敗由本體修；歸因為「基線磁鐵不足以補償探針偏移」的，升級為本體。
粘連風險：基線與本體若功能過度重疊，會讓同一品質要求在兩個層級重複競爭。防止方法是**功能分離**——基線用品質語言（一致性、說服力、張力），本體用過程語言（擴張、檢證、比較）。品質與過程的職責不同，避免互相取代。

### 10.6 修改的反模式
- **格式塔損失**：只看被改的一句，不追蹤探針連鎖效益；引擎探針的修改影響所有任務的多個步驟
- **身分－過程脫耦**：新身分與身分原則的方向與過程 Key 不相容
- **維度膨脹**：不斷追加 Key 不淘汰重疊者，觸發全面稀釋
- **拔工序不接功能**：移除回應格式區塊而未確認其結算功能有他處承接
- **以距離為判準**：誤以「與域任務的映射距離≤1」判斷探針是否可改；正確量綱是功能保存與方向對準（§10.3）
- **閘門遺漏**：複製通用封堵 Key 但未追加域專屬逃逸路徑的競爭 Key
